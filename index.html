crap-rs — CRAP scorecard reports

Hosted HTML reports from the crap-rs CRAP (Change Risk Anti-Patterns) analyzer.

This site hosts the analyzer's own dogfood scorecards:

  • The production report for the latest main commit.
  • A per-pull-request report under /pr-<number>/, showing that branch's CRAP and the delta against its base branch.

Each pull request links to its own report from a comment on the PR.
